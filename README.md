# FAZIX Esports — Official Website

Official website for **FAZIX Esports** (`fazix.gg`), built with [Next.js 16](https://nextjs.org/) App Router, [React 19](https://react.dev/), and TypeScript.

---

## ⚡ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19
- **Language**: TypeScript
- **Styling**: Vanilla CSS Modules & Modern CSS Design System
- **Icons**: Lucide Icons (`lucide-react`)
- **Smooth Scroll**: Lenis (`lenis`)

---

## 🚀 Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Start the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build

```bash
npm run build
npm run start
```

## 📁 Project Structure

```
├── app/              # Next.js App Router (pages, layout, API routes, sitemap, robots)
├── components/       # UI & Client components (Navbar, Footer, Hero, Matches, Modals, etc.)
├── context/          # React Context providers (Cookie consent, modals, etc.)
├── data/             # Static & dynamic site data (news, roster, matches, achievements)
├── docs/             # Documentation & DSGVO/GDPR records
├── lib/              # Shared utility functions
├── public/           # Static assets, branding logos, favicons, audio
└── next.config.mjs   # Next.js configuration
```
